NeuroLog GitHub Pages edition (based on v8.2).

Create a PUBLIC GitHub repository named neurolog (do not upload any patient or case backup data). Upload all files in this folder to the ROOT of the repository. Commit changes. Open Settings > Pages > Build and deployment > Deploy from a branch; select main and /(root), then Save. The website URL will be https://YOUR-USERNAME.github.io/neurolog/ .

The manifest icon paths are relative, compatible with GitHub Pages project URLs. The app stores cases locally per device and origin. Export a JSON backup from the old app before moving; import it into the new site. Keep the old app until the new site is verified. This prototype is not encrypted: use fictional data only.
